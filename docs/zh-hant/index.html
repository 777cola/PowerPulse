01

五個面板，只答一個問題：啲數對唔對得上。

牆插俾咗幾多、系統食咗幾多、電池入咗幾多，三筆數一定要加得埋。對唔上，即係有嘢喺背後偷偷食電。

功率流

由牆插到電池，一條帶睇晒。粗細跟住瓦數走：充電嗰陣充電器分兩路，一路餵系統一路餵電池；充電器唔夠力，就同電池一齊餵系統。

  • 三個節點：牆插、系統、電池
  • 帶嘅粗細用 0.7 次方壓縮，低功率都分得出
  • 末端嘅箭嘴標明能量方向

系統監控

CPU、GPU、記憶體佔用，再加一份按能耗排嘅程序榜。

  • CPU / GPU / 記憶體三條即時曲線
  • 程序榜讀 rusage_info_v6，唔使 root
  • 能耗用差分計，直接出瓦數

充電歷史

上次充咗幾多 Wh、呢個禮拜每日幾多，仲有一鍵匯出 CSV。

  • SQLite 寫落磁碟，過咗午夜都唔會唔見
  • 拔咗線之後，上次充電紀錄照樣留住
  • 匯出失敗會講明原因，唔會扮成功

充電器

傾到幾多伏幾多安、支援邊幾個 PD 檔位、點解跑唔滿。

  • 讀到廠商同型號（有啲充電器唔上報）
  • PD 檔位表會標出而家用緊邊一檔
  • 跑唔滿會俾結論：涓流、過熱保護，定係線材問題

設定

取樣間隔、歷史保留、通知門檻、選單列顯示同語言。

  • 選單列可以顯示圖示 + 百分比 + 功率
  • 低電量、充滿、高溫、慢充四類通知
  • 簡體 / 繁體 / English
