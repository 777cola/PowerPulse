選單列裡，看清每一瓦。

每秒取樣一次，把壁插輸出、系統功耗、電池充電功率拆開顯示。插上充電器那一刻，就知道這套充電組合到底跑了多少。

01

五個面板，只回答一件事：這些數字對不對得上。

壁插給了多少、系統吃了多少、電池進了多少，三筆必須能互相加減。對不上，就代表有地方在偷偷耗電。

功率流

從壁插到電池，一條帶子說清楚。粗細跟著瓦數走：充電時充電器分成系統與電池兩路；充電器不夠用時，充電器和電池一起餵系統。

  • 三個節點：壁插、系統、電池
  • 帶子粗細按 0.7 次方壓縮，低功率也看得出差別
  • 末端的箭頭標明能量方向

系統監控

CPU、GPU、記憶體佔用，加上一份依能耗排序的程序榜。

  • CPU / GPU / 記憶體三項即時曲線
  • 程序榜讀 rusage_info_v6，不需要 root
  • 能耗以差分換算成瓦數顯示

充電歷史

最近一次充進去多少 Wh、近一週每天多少，一鍵匯出 CSV。

  • SQLite 寫入磁碟，跨日不遺失
  • 最近一次充電結束後仍然保留
  • 匯出失敗會直接說明原因，不會假裝成功

充電器

協商到幾伏幾安、支援哪些 PD 檔位、為什麼沒跑滿。

  • 讀出廠商與型號（部分充電器不上報）
  • PD 檔位表標出目前使用的那一檔
  • 跑不滿時給結論：涓流、溫控，還是線材

設定

取樣間隔、歷史保留、通知閾值、選單列顯示與語言。

  • 選單列可顯示圖示 + 百分比 + 功率
  • 低電量、充滿、高溫、慢充四類通知
  • 簡體 / 繁體 / English
