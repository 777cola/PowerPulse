温度功能 — 整体架构

数据采集层 → 处理层 → 展示层

架构总览
📡 数据采集层 — TemperatureMonitor (新增)
SMC (AppleSMC IOService) → IOKit 读取 SMC Key
默认 Key：TC0P（CPU）、TG0P（GPU）、TB0T（电池）
发现阶段：枚举 SMC 所有可读 Key，构建传感器目录
采样间隔：2 秒，MovingAverage(5) 平滑
▼
⚙️ 处理层
TemperatureMonitor: ObservableObject, @Published
SensorCatalogStore: 用户自定义配置持久化 (JSON)
可发现 Key 列表 + 用户启用/禁用 + 排序记录
热力图数据缓冲：150 样本 (5分钟窗口)
▼
🖥 展示层 — TemperatureTabView
温度渐变条 (绿→黄→红) + 实时数值
底部热力图矩阵 (传感器 × 时间)
顶部齿轮 → 管理模式 (拖拽排序 + 开关)

与现有架构的关系

集成方式
AppDelegate 新增持有 TemperatureMonitor()
LivePanelView 新增第 5 个 Tab：「🌡 温度」
Tab 排序：功率流 | 系统监控 | 温度 | 历史 | 关于
与 BatteryMonitor / SystemMonitor 同级注入，完全独立

设计原则

  • 与现有架构完全平行，不修改任何现有 Monitor
  • SMC 读取复用项目已链接的 IOKit 框架
  • 温度条配色与 macOS 深色模式毛玻璃自然融合

技术挑战

  • SMC Key 枚举无官方文档，需验证兼容各 Mac 机型
  • Apple Silicon 上 SMC 行为可能与 Intel 不同
