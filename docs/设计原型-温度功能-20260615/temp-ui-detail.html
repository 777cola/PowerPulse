交互细节

  • 管理模式通过 matchedGeometryEffect 平滑过渡
  • 拖拽使用 SwiftUI onMove 原生手势
  • 「+ 添加」弹出可用传感器列表（来自 SMC 枚举结果）
  • 热力图每 2 秒追加新列，最右为最新

注意事项

  • 不同 Mac 机型 SMC Key 集合不同，空列表需要空状态提示
  • 热力图单元格颜色基于该传感器自身 min/max 归一化
